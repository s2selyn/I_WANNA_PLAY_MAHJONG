# 🀄 I WANNA PLAY MAHJONG

**디스코드에서 버튼으로 즐기는 3인 / 4인 리치마작 봇**

[![Python](https://img.shields.io/badge/Python-3.10+-3776AB?logo=python&logoColor=white)](https://python.org)
[![discord.py](https://img.shields.io/badge/discord.py-2.3+-5865F2?logo=discord&logoColor=white)](https://discordpy.readthedocs.io/)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

패 기호나 명령어를 외울 필요 없이 **타일 버튼을 클릭**해서 플레이해요 — 개발자가 아니어도 편하게!
쯔모·론·리치·후로(치/퐁/깡)·도라·역/점수 계산까지 포함한 실제 룰 기반 엔진을 갖췄습니다.

📖 [사용법 가이드](docs/사용법.md) · ☁️ [배포 가이드](docs/배포-oracle.md) · 🔊 [효과음 설정](sounds/README.md)

## 🕹 이렇게 플레이해요 (버튼)

1. 채널에 `!mj` (4인) 또는 `!mj 3` (3인) 입력 → **로비**가 열립니다 (명령어 친 사람이 **방장**)
2. 나머지 플레이어는 **참가** 버튼 클릭 (누구나 가능)
3. **시작** 버튼 클릭 → 이후는 전부 **버튼**으로 진행

> 👑 **방장 전용 버튼**: `시작` · `취소` · `AI 추가` · `손패 방식 전환` · `빈자리 AI 채우고 시작`.
> 사람이 안 모이면 방장이 **빈자리 AI 채우고 시작**을 누르면 남은 자리를 AI로 채워 바로 시작해요.
> (선택) **손패 방식 전환**으로 아래 두 방식 중 하나를 고를 수 있어요.

### 손패를 보는 두 가지 방식 (기본값은 로비에서, 개인 설정은 게임 중에)

| 방식 | 손패 보기 | 추천 |
|---|---|---|
| 📱 **채널(모바일)** *(기본값)* | 채널의 **🎴 내 손패** 버튼을 누르면 **나만 보이는(ephemeral)** 손패가 그 채널에 떠요. DM ↔ 서버 전환이 없어 **모바일에 최적** | 폰으로 할 때 |
| 💻 **DM(PC)** | 내 차례가 되면 **봇이 DM으로 손패를 자동 전송**. PC에서 두 창 띄우기 좋아요 | PC로 할 때 |

- 방장이 정한 건 **기본값**일 뿐이고, 각자 **⚙️ 내 방식** 버튼으로 자기 것만 바꿀 수 있어요
  (로비에서도, 게임 중에도). 한 방에 **모바일파와 PC파가 섞여 있어도** 각자 편한 방식으로 플레이해요.
- 개인 선택은 `data/prefs.json` 에 기억돼서 **다음 판부터 자동 적용**돼요
  (디스코드 유저 ID와 방식만 저장 · gitignore 처리 · `MJ_DATA_DIR` 로 경로 변경 가능).
- 남이 버리면 **🔔 콜** 버튼(채널) 또는 DM으로 **론/퐁/치/깡/스킵** 이 떠요.
- 버림패·도라·점수·차례 등 **공용 바닥**은 채널 보드에 실시간 표시돼요 (모두 같이 봄).

> ⚠️ **DM 방식**을 쓸 땐 봇에게 **DM 허용**을 켜야 해요
> (서버명 우클릭 → 개인정보 보호 → "서버 멤버의 다이렉트 메시지 허용").
> 채널(모바일) 방식은 DM이 필요 없어요.

## ✨ 기능

- **3인(산마) / 4인** 리치마작 지원
- 완전한 화료 판정: 일반형 + 치또이쯔(7쌍) + 코쿠시(국사무쌍)
- **역 판정**: 리치·더블리치·잇파츠·멘젠쯔모·핑후·탕야오·이페코·역패·산쇼쿠·잇쓰·찬타·준찬·토이토이·산안커·혼이쓰·친이쓰·료안페코·소산겐·혼로토 등
- **역만**: 국사무쌍·스안커·다이산겐·소/다이스시·쓰이소·친로토·료이소·추렌포토·스깡쓰·천화·지화
- **점수 계산**: 판/부(fu) 계산, 만관~역만, 딜러/자 구분, 쯔모 분할, 혼바·리치봉
- 도라 / 뒷도라 / 적도라(빨간 5) 지원
- 후리텐(자기 버림패 / 리치 후리텐) 처리
- 부족한 자리는 간단한 **AI**로 채워서 시작 가능
- 🔊 **음성 채널 효과음(선택)** — 리치·론·쯔모·퐁/치/깡 순간에 소리 재생.
  서버 관리자가 `!mj sound` 로 **그 서버만의 효과음**을 업로드할 수 있어요 ([설정](sounds/README.md))

각 플레이어의 손패는 **DM으로 비공개** 전송되고, 버림패·후로·도라 등 공개 정보는 채널에 표시됩니다.

> 🔊 효과음을 쓰려면 `sounds/` 폴더에 오디오 파일을 넣고(파일명 규칙은 [sounds/README.md](sounds/README.md)),
> 호스트에 **FFmpeg** 가 설치돼 있어야 해요. `!mj` 친 사람이 음성 채널에 있으면 봇이 자동 입장해요.
> (파일이 없거나 음성 미사용이면 그냥 조용히 텍스트로만 진행돼요.)

## 🚀 설치 & 실행

지인들끼리 **놀고 싶을 때만 내 컴퓨터에서 켜는** 방식이에요. 24시간 호스팅 필요 없어요.

### 처음 한 번만 (준비)

**1. 디스코드 봇 만들기**
1. https://discord.com/developers/applications → **New Application** 으로 봇 생성
2. 왼쪽 **Bot** 메뉴 → **Privileged Gateway Intents** 에서
   `MESSAGE CONTENT INTENT` 를 **켜기** (필수! 안 켜면 `!mj` 를 못 읽어요)
3. **Reset Token** → 토큰 복사 (비밀번호처럼 취급, 남한테 공유 금지)
4. 왼쪽 **OAuth2 → URL Generator** → `bot` 스코프 +
   `Send Messages`, `Read Message History`, `Embed Links` 권한 →
   생성된 URL 로 내 서버에 초대

**2. 토큰 넣기**
`.env.example` 을 `.env` 로 복사하고, 그 안에 토큰을 붙여넣기:
```
DISCORD_TOKEN=여기에_복사한_토큰
```
`.env` 는 `.gitignore` 에 있어서 실수로 깃허브에 올라가지 않아요.

**3. 파이썬 준비** (없으면 https://python.org 에서 설치)

### 놀고 싶을 때마다

- **윈도우**: `run.bat` 더블클릭
- **맥 / 리눅스**: 터미널에서 `./run.sh`
- (또는 어디서든) `python bot.py`

`Logged in as ...` 가 뜨면 켜진 거예요. 디스코드 채널에서 **`!mj`** 입력 → 로비 시작!
다 놀았으면 그 창에서 **Ctrl+C** 로 끄면 됩니다.

> ⚠️ 플레이어들은 봇에게 **DM 허용**을 켜야 손패를 받아요
> (서버명 우클릭 → 개인정보 보호 → "서버 멤버의 다이렉트 메시지 허용").

### ☁️ 24/7 로 돌리고 싶다면 (클라우드)

폰/PC를 안 켜놔도 봇이 항상 살아있게 하려면 **오라클 클라우드 무료 VM** 에 올리면 돼요.
`deploy/setup.sh` 한 줄 설치 + systemd 자동 시작까지 — [배포 가이드](docs/배포-oracle.md) 참고.

## 🎮 명령어

채팅으로 입력하는 명령어는 **딱 하나**, 로비를 여는 것뿐이에요. 나머지는 전부 버튼입니다.

| 명령어 | 설명 |
|---|---|
| `!mj` | 4인 로비 열기 |
| `!mj 3` | 3인 로비 열기 |
| `!mj sound` | 🔊 효과음 목록 / 등록 / 삭제 (등록·삭제는 **서버 관리자**만) |
| `!mj voice` | 🎙 봇을 지금 내가 있는 음성 채널로 부르기 (`leave` 로 내보내기) |
| `!mj help` | 도움말 |

로비를 연 뒤에는 **참가 / AI 추가 / 시작 / 취소** 버튼으로 진행하고,
게임 중에는 DM으로 오는 **타일 버튼**과 **론/퐁/치/깡/쯔모/리치/깡/스킵** 버튼만 누르면 돼요.

## 🗂 구조

```
.
├── bot.py                 # 디스코드 명령어 + 게임 진행 드라이버
├── requirements.txt
├── .env.example
├── LICENSE
├── run.sh / run.bat       # 로컬 실행 스크립트
├── deploy/                # 오라클 클라우드 배포 (systemd + 설치 스크립트)
├── docs/                  # 사용법 · 배포 가이드
├── sounds/                # (선택) 음성 채널 효과음 파일
├── mahjong/               # 순수 파이썬 마작 엔진 (디스코드 비의존)
│   ├── tiles.py           # 패 표현 / 표기법 파싱 / 패산 구성
│   ├── meld.py            # 후로(치/퐁/깡) 표현
│   ├── wall.py            # 패산·왕패·도라 표시패·영상패
│   ├── player.py          # 플레이어 상태(손패/버림/리치/텐파이/후리텐)
│   ├── agari.py           # 화료형 분해 (일반형/치또이/국사)
│   ├── shanten.py         # 텐파이/대기패 판정
│   ├── context.py         # 화료 컨텍스트 & 파싱된 멘쯔
│   ├── yaku.py            # 역/역만 판정
│   ├── score.py           # 부·판·도라·점수 계산 (최적 해석 선택)
│   ├── game.py            # 한 국(round) 상태 기계: 턴/콜/리치/깡/유국/점수 이동
│   └── render.py          # 손패/버림패/점수 텍스트 렌더링
└── tests/
    ├── test_engine.py     # 역/점수/화료 단위 테스트
    ├── test_game.py       # 한 국 전체 자동진행 무결성(점수 보존)
    └── test_calls.py      # 퐁/치/깡/리치 경로 스트레스 테스트
```

엔진(`mahjong/`)은 디스코드에 의존하지 않으므로 다른 인터페이스(CLI/웹)에도 재사용할 수 있습니다.

## ⚙️ 규칙 옵션 (`mahjong/game.py` 의 `GameConfig`)

- `three_player` — 3인(산마) 여부
- `red_fives` — 적5 사용
- `kuitan` — 쿠이탕(먹은 탕야오 인정)
- `starting_points` — 시작 점수 (기본 25000)
- `kiriage` — 끊어올림 만관

## 📌 알려진 단순화

현재 버전에서 아직 다루지 않는 세부 규칙들:

- 4개 리치/9종9패/4깡 유국 등 도중 유국(abortive draw)
- 나가시만관, 두 명 이상의 깡 경합 세부 처리
- 파오(책임 지불), 3인 마작의 츠모손(북 지불) 세부 규정
- 대국 종료 조건은 "누군가 0점 미만"으로 단순화 (동/남장 지정 종료 미구현)

엔진은 모듈화되어 있어 위 규칙들을 점진적으로 추가하기 쉽습니다.
