# 🀄 리치마작 봇 사용법

> 마작 룰은 안다는 가정하에, **봇 조작(버튼) 흐름**만 정리한 가이드예요.
> 모든 진행은 채널의 **버튼**으로 이뤄져요. 채팅으로 패를 입력할 일은 없어요.

---

## 1. 게임 열기

채널에 아래 명령어를 입력하면 **로비**가 열려요. (명령어 친 사람이 **방장** 👑)

| 명령어 | 설명 |
|---|---|
| `!mj` | 4인 게임 로비 |
| `!mj 3` | 3인(산마) 게임 로비 |
| `!mj help` | 간단 도움말 |

---

## 2. 로비

- **참가** — 누구나 눌러서 자리에 앉아요.
- 아래 버튼은 **방장 전용** 👑 (남이 누르면 "방장만 할 수 있어요"):
  - **시작** — 자리가 다 찼을 때 대국 시작
  - **빈자리 AI 채우고 시작** — 남은 자리를 AI 🤖로 채우고 바로 시작 *(사람 부족할 때)*
  - **AI 추가** — 빈자리에 AI 하나 추가
  - **손패 방식 전환** — 아래 두 방식 중 선택
  - **취소** — 로비 닫기

---

## 3. 손패를 보는 두 가지 방식

로비에서 **손패 방식 전환**으로 골라요.

### 📱 채널(모바일) — 기본값
- 채널의 **🎴 내 손패** 버튼을 누르면 **나만 보이는(비공개)** 손패가 그 채널에 떠요.
- DM ↔ 서버 전환이 없어서 **폰에 편해요.**
- 내 차례엔 `▶️ @너 차례` 핑이 오니, 그때 **🎴 내 손패**를 누르면 돼요.

### 💻 DM(PC)
- 내 차례가 되면 봇이 **DM으로 손패를 자동 전송.**
- PC에서 창 두 개 띄우기 좋아요.
- ⚠️ 봇 DM을 받으려면 서버 **개인정보 보호 → "서버 멤버의 다이렉트 메시지 허용"** 을 켜야 해요.

> 공용 바닥(버림패·도라·점수·차례)은 두 방식 모두 **채널 보드에 실시간**으로 같이 보여요.

---

## 4. 내 차례에 하는 것

손패가 뜨면 아래 버튼이 (상황에 따라) 나와요:

- **🀫 타일 버튼** — 누르면 그 패를 **버려요.** (쯔모한 패는 맨 뒤에)
- **🀄 쯔모** — 쯔모 화료가 가능할 때
- **🎏 리치** — 리치 가능할 때 → 누르면 **버릴 패를 한 번 더** 골라요
- **🔶 깡** — 안깡/가깡 가능할 때 → 깡할 패 선택

> 오래 안 누르면(AFK) 자동으로 한 장 버려져서 게임이 멈추지 않아요.

---

## 5. 콜 (남이 버렸을 때)

누군가 패를 버려서 내가 콜할 수 있으면 알림이 떠요.
- **📱 채널 방식**: `🔔 콜` 버튼을 눌러 **나만 보이는** 콜 창을 열어요.
- **💻 DM 방식**: DM으로 콜 창이 와요.

콜 버튼: **🀄 론 · 퐁 · 깡 · 치 · 스킵**
- 제한 시간 안에 아무것도 안 누르면 **자동 스킵**이에요.

---

## 6. 한 국이 끝나면

점수 정산이 채널에 뜨고, 아래 버튼이 나와요:
- **▶️ 다음 국** — 다음 국 진행 (친 이동/연장 자동 처리)
- **🎌 종료** — 대국 끝

---

## ⚡ 빠른 요약

1. `!mj` (또는 `!mj 3`) 로 방 열기 → 친구들 **참가**
2. 방장이 **손패 방식** 고르고 → **시작** (사람 없으면 **빈자리 AI 채우고 시작**)
3. 내 차례 → **🎴 내 손패**(모바일) 또는 DM에서 → 패 버리기/쯔모/리치/깡
4. 남이 버리면 → **🔔 콜** → 론/퐁/치/깡/스킵
5. 국 끝 → **다음 국** 또는 **종료**

즐마! 🀄
