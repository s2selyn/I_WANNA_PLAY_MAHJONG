# 🀄 타일 이미지

디스코드 **애플리케이션 이모지**로 올려서 쓰는 마작패 이미지예요 (96×128 PNG).

## 출처 / 라이선스

[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles) —
**CC0 1.0 (퍼블릭 도메인)**. 별도의 저작자 표시 의무는 없지만 감사히 쓰고 있어요.

원본(600×800)을 디스코드 이모지 한도(256KB)에 맞게 96×128 로 줄였습니다.

## 파일 이름

| 파일 | 패 |
|---|---|
| `m1`~`m9` | 만수 1~9 |
| `p1`~`p9` | 통수 1~9 |
| `s1`~`s9` | 삭수 1~9 |
| `z1`~`z7` | 동·남·서·북·백·발·중 |
| `m0` `p0` `s0` | 적5 (빨간 5) |

## 사용법

봇 소유자가 한 번만 실행하면 돼요:

```
!mj emoji install    # 애플리케이션 이모지로 업로드 (모든 서버에서 사용 가능)
!mj emoji status     # 현재 적용 상태 확인 (누구나)
!mj emoji remove     # 제거하고 유니코드 문자로 되돌리기
```

애플리케이션 이모지는 **봇 앱에 소속**되므로 서버마다 올릴 필요가 없고,
각 서버의 이모지 슬롯도 차지하지 않아요.
