# 🔊 효과음 폴더

봇이 **음성 채널에서** 해당 순간에 효과음을 재생해요.
파일이 **없으면 그냥 조용히 넘어가요** (있는 것만 재생).

효과음을 넣는 방법은 **두 가지**예요:

| 방법 | 적용 범위 | 누가 |
|---|---|---|
| 🌐 이 폴더에 파일 넣기 | **모든 서버 공통** (기본 효과음) | 봇을 돌리는 사람(호스트) |
| 💬 디스코드에서 `!mj sound` 업로드 | **그 서버에서만** | 그 서버의 **관리자** |

같은 이름이면 **그 서버에 업로드된 게 우선**이고, 없으면 이 폴더의 기본 효과음을 써요.
업로드된 파일은 `sounds/<서버ID>/` 에 저장되며 깃에는 올라가지 않아요.

## 💬 디스코드에서 등록하기 (서버 관리자 전용)

```
!mj sound                  # 이 서버의 효과음 목록 (누구나 조회 가능)
!mj sound riichi           # ← 음성파일을 첨부해서 전송하면 등록/교체
!mj sound clear riichi     # 삭제 (clear all 이면 전체 삭제)
```

- 지원 형식 `.mp3` `.ogg` `.wav` `.m4a` · 최대 **1MB** · **1~3초** 권장
- **서버 관리** 권한이 있는 사람만 등록/삭제할 수 있어요.
- 삭제하면 기본 효과음이 있는 경우 그걸로 되돌아가요.

## 파일 이름 규칙

아래 이름으로 넣으면 자동 인식돼요. 확장자는 `.mp3`, `.ogg`, `.wav`, `.m4a` 중 아무거나:

| 파일명 | 재생 순간 |
|---|---|
| `riichi` | 리치 선언 🎏 |
| `ron` | 론 화료 🀄 |
| `tsumo` | 쯔모 화료 |
| `pon` | 퐁 콜 |
| `chi` | 치 콜 |
| `kan` | 깡 콜 |

예: `riichi.mp3`, `ron.wav` … (디스코드 업로드 때도 같은 이름을 써요)

## 🎲 한 이벤트에 여러 종류 넣기

같은 이름 뒤에 **숫자를 붙이면** 여러 개를 등록할 수 있고, 그때마다 **랜덤으로 하나**가 재생돼요.

```
tsumo.mp3    tsumo2.mp3    tsumo3.m4a    tsumo4.wav    ← 쯔모 4종 랜덤
chi.mp3      chi2.mp3                                  ← 치 2종 랜덤
```

- 확장자는 섞여도 돼요 (`.mp3` + `.wav` 같이)
- `tsumo_2.mp3`, `tsumo-2.mp3` 처럼 `_`/`-` 를 넣어도 인식해요
- 디스코드에서는 `!mj sound add tsumo` 로 하나씩 추가하거나,
  `!mj sound tsumo` 에 **파일 여러 개를 한 번에 첨부**해도 돼요

## 어떻게 동작하나요?

- `!mj` 를 친 사람이 **음성 채널에 들어가 있으면** 봇이 그 채널에 자동 입장해요.
- 위 순간이 오면 해당 효과음을 재생해요 (여러 개가 겹치면 순서대로).
- 대국이 끝나거나 로비를 취소하면 봇이 음성에서 자동 퇴장해요.

## 효과음은 어디서 구하나요?

저작권 문제로 기본 제공은 안 해요. 무료 효과음 사이트에서 받아서 넣으세요:

- [freesound.org](https://freesound.org) (CC 라이선스)
- [pixabay.com/sound-effects](https://pixabay.com/sound-effects/)
- [mixkit.co/free-sound-effects](https://mixkit.co/free-sound-effects/)

> 짧은 효과음(1~3초) 권장. 파일이 너무 길면 다음 효과음이 밀려요.

## 필요 조건

- 서버(호스트)에 **FFmpeg** 설치 (오라클 setup.sh 는 자동 설치)
- `pip install -r requirements.txt` (PyNaCl 포함)
- 봇에게 음성 채널 **연결(Connect) + 말하기(Speak)** 권한
